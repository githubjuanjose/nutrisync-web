4 · La saga del correo: cuatro capas, un diseño mejor

  1. to: como string con comas → denomailer exige array («No valid emails») — y la escalación llevaba 2 días muda por lo mismo.
  2. Multi-destinatario → IONOS lo veta desde IPs de Supabase (554 policy).
  3. 11 envíos secuenciales → WORKER_RESOURCE_LIMIT (546): la CPU del Edge no da para tanta ceremonia TLS.
  4. La ráfaga de pruebas → «450 Mail send limit exceeded»: cuota del remitente agotada (capturada LITERAL con un envío de control desde el Mac — auth 235 ✓, sender-match ✓).

El diseño final es la moraleja: UN envío diario al alias founders@ y el fan-out lo hace IONOS desde su propia casa (7 buzones del dominio, creados hoy con credenciales en secrets/). Verificado en vivo: el digest llegó con el formato nuevo — [FB1] NS-0009 «…» + RESPUESTAS ENVIADAS. El error SMTP literal ahora viaja en la respuesta JSON (filosofía nsFail, v9).
